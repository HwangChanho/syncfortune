# キャンセル・返金ポリシー

**最終改定日: 2026-09-04**

本ポリシーは韓国「電子商取引等における消費者保護に関する法律」に従います。
本ポリシーが法令に反する場合、法令が優先します。

## 1. 有料通貨「woon」

有料コンテンツは **woon** で利用し、1つ開くごとに所定数が消費されます。
woon は**個別に消費される**ため「可分的デジタルコンテンツ」に当たり、
**未使用の woon は「提供が開始されていない部分」**とみなします。

## 2. 返金の基準

### 2.1 ウェブで決済した場合

| | |
|---|---|
| **期間** | 決済日から **7日以内** |
| **範囲** | **未使用の woon のみ** |
| **金額** | 返金する woon 数に**比例**した額（例: 600woon を36,000ウォンで購入し200woon残 → 12,000ウォン） |
| **方法** | 決済した手段へ返金 |

> ⚠️ **使用済みの woon は返金されません** — そのコンテンツは既に提供済みです。

### 2.2 アプリ（App Store・Google Play）で決済した場合

決済・キャンセル・返金は**各ストアのポリシー**に従います。ストアへ直接ご請求ください。
当方はストアの決済情報を保有しておらず、直接取り消すことができません。

### 2.3 無償で受け取った woon

イベント・ボーナス・プレゼント・クーポン等で無償付与された woon は**返金対象外**です。

## 3. 未成年者の決済

**満19歳未満**が法定代理人の同意なく行った決済は**取り消すことができます**（韓国民法第5条）。
上記7日間とは**無関係**に行使できます。

## 4. 申請方法

アプリ・ウェブの **[設定 → お問い合わせ]** から、**決済日と注文番号**をお知らせください。
営業日基準 **3日以内**にご案内します。

## 5. サービス終了時

残っている**有償の** woon は、終了告知に記載する方法で返金します。
